# 02 技术时间线白名单

> 原则（R1）：项目窗口 **2025.2 – 2025.7**。一项技术只有在"决策当时"已发布、且在华为内网（镜像仓库 / 昇腾生态）中合理可得，才能被选用。
> - **可用**：项目开始前已发布且成熟
> - **窗口内出现**：项目期间发布，只能在其发布日期之后被"发现/评估/切换"，且需考虑内部引入周期（通常数周）
> - **禁用**：2025.7 之后发布，严禁出现
>
> 日期标注 `≈` 表示月份级精度；标注 `需确认` 表示记忆不够可靠，引用前要再核实。

## 5. 维护规则
- 每次技术选型，在 `04_架构与决策记录.md` 的 ADR 中写明"所选技术的发布时间 ≤ 决策时间"。
- 发现记忆不准的日期，在本表修正并记录修正日期。
