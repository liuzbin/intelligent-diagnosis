# intelligent-diagnosis

智能诊断系统（项目复盘与技术脚手架）。

基于知识库检索增强生成（RAG）：测试工程师发起诊断请求，系统从故障知识库中检索相关案例，给出最可能的 Top3 故障原因及置信度。

> 本仓库为**框架级脚手架**：工程结构完整（高可用、高并发、降延迟、双路召回、混合检索、重排等），业务逻辑抽象化，用于阅读与学习，不保证可直接运行。
